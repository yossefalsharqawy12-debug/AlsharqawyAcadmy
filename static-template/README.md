# قالب أكاديمية الأستاذ (Static Serverless Template)

هذا القالب مصمم ليكون خفيفاً وسريعاً ولا يتطلب أي سيرفر (Backend). يمكنك استضافته مجاناً على **GitHub Pages** أو أي استضافة ملفات ثابتة.

## طريقة العمل والمعمارية (هام للمدرسين):
لأن هذا القالب يعمل بدون سيرفر، لا توجد قاعدة بيانات لحفظ التغييرات. بدلاً من ذلك، نستخدم ملف إعدادات ذكي `config.js`.

### كيف تقوم بتعديل الموقع؟
1. افتح ملف `admin.html` في متصفحك.
2. كلمة المرور الافتراضية هي: `1234`.
3. قم بتعديل الألوان، النصوص، والروابط كما تحب في لوحة التحكم.
4. عند الانتهاء، اضغط على زر **"حفظ وتوليد ملف config.js"**.
5. سيتم تحميل ملف جديد باسم `config.js` إلى حاسوبك.
6. انسخ هذا الملف وضعه داخل مجلد `js/` ليقوم باستبدال الملف القديم.
7. سيتم تحديث الموقع فوراً بهذه الإعدادات.

### كيف تضيف تطبيق الـ APK؟
نظراً لعدم وجود سيرفر للرفع عليه، طريقة "الحقن" المحلية لا تعمل مع الطلاب لأن أجهزتهم منفصلة عن جهازك. الطريقة الصحيحة والهندسية للمواقع الثابتة هي:
1. قم بتجهيز تطبيق الأندرويد الخاص بك (ملف الـ APK).
2. قم بإعادة تسمية الملف ليصبح بالضبط: `app.apk`.
3. ضع هذا الملف داخل المجلد الرئيسي للقالب (بجوار ملف `index.html`).
4. عند رفع المجلد إلى GitHub Pages، سيقوم زر التحميل في الموقع بتنزيل هذا الملف للطلاب بشكل مباشر وسريع.

## طريقة الرفع على GitHub Pages
1. قم بإنشاء حساب على GitHub إذا لم يكن لديك.
2. قم بإنشاء مستودع جديد (New Repository).
3. قم برفع كل ملفات هذا المجلد إلى المستودع.
4. اذهب إلى إعدادات المستودع (Settings) -> ثم صفحات (Pages).
5. اختر (Deploy from a branch) واختر الفرع `main`.
6. سيقوم GitHub بإعطائك رابط الموقع المجاني الخاص بك، شاركه مع طلابك!
